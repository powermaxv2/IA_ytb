- Nouvel outil sur la page d'accueil : **QR code**. Il lit un QR code ou un code-barres avec l'appareil photo, en direct, ou sur une image du téléphone (capture d'écran, photo). Gulp demande l'accès à l'appareil photo la première fois seulement ; sans lui, la lecture depuis une image marche toujours.
- Gulp comprend ce qu'il lit : un **lien** (ouvert seulement quand vous touchez le bouton), un **réseau Wi-Fi** (« Se connecter » en un geste sur Android 11 et plus, sinon le mot de passe est copié et les réglages Wi-Fi s'ouvrent), un **contact** (ajouté au carnet), un e-mail, un numéro, un SMS, un lieu, un texte, ou le **code-barres** d'un produit.
- **Créer** : un lien, un texte, votre Wi-Fi (pour vos invités) ou un contact devient un QR code avec le logo Gulp au milieu. Il s'enregistre en image dans Pictures/Gulp, ou se partage directement.
- **Derniers scans** : les 8 derniers codes restent sur le téléphone (jamais envoyés), un bouton les efface.
- Tout se passe sur le téléphone, sans connexion.
